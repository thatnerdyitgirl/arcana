# Telegram-бот Arcana Zen (напоминания и карта дня)

Бот работает на бесплатном тарифе Cloudflare: **Worker** (код) + **D1** (маленькая база) + **Cron** (будильник раз в минуту).
Бот хранит только номер чата, часовой пояс и выбранное время. Токен бота живёт только в настройках Worker.

Что умеет:
- `/utro 08:00` — каждое утро присылает картинку «карта дня»
- `/med 22:22` — напоминание о медитации
- `/karta`, `/sovet` — карта дня и совет Будды по запросу (кнопка «Ещё совет» открывает совет в приложении)
- `/matrix 14.03.1992`, `/pair 14.03.1992 02.11.1990` — Матрица судьбы и совместимость прямо в чате (дата проходит через Telegram и бота, бот её не сохраняет). Без даты команды открывают приложение, где даты считаются только на устройстве
- `/luna 09:00` — сообщение в день новолуния и полнолуния (даты считает сайт заранее на ~3 года вперёд)
- `/tz +5` — часовой пояс (по умолчанию Астана, +5), `/status`, `/stop`

## Установка (один раз, примерно 15 минут)

Всё делается в браузере на dash.cloudflare.com. Названия кнопок в Cloudflare иногда меняются: ориентируйся на смысл.

1. **Создай Worker.** Слева «Workers & Pages» → «Create» → вкладка **Workers** (не Pages!) → «Hello World» → имя `arcana-bot` → «Deploy».
2. **Вставь код.** Кнопка «Edit code» → удали всё в окне → вставь весь текст из файла `bot/worker.mjs` → «Deploy».
3. **Создай базу.** Слева «Storage & databases» → «D1 SQL database» → «Create database» → имя `arcana-db` → «Create».
   Открой базу → вкладка «Console» → вставь текст из `bot/schema.sql` → «Execute».
4. **Подключи базу к Worker.** Worker `arcana-bot` → «Settings» → «Bindings» → «Add» → «D1 database» → имя переменной ровно `DB` → выбери `arcana-db` → «Deploy».
5. **Секреты.** Worker → «Settings» → «Variables and Secrets» → «Add»:
   - тип **Secret**, имя `BOT_TOKEN`, значение: токен бота из @BotFather (вставляешь только ты, нигде больше его не показывай);
   - тип **Secret**, имя `WEBHOOK_SECRET`, значение: любая длинная случайная строка из букв и цифр (запомни её);
   - тип **Text**, имя `SITE`, значение `https://arcanazen.pages.dev`.
   Нажми «Deploy».
6. **Будильник.** Worker → «Settings» → «Triggers» → «Cron Triggers» → «Add» → `* * * * *` (раз в минуту).
7. **Подключи бота.** Открой в браузере адрес (подставь свои значения): `https://arcana-bot.ТВОЙ-ПОДДОМЕН.workers.dev/setup?key=ТВОЙ_WEBHOOK_SECRET`
   Должно появиться «Готово: бот подключён.»
8. Напиши боту `/start`, потом `/utro 08:00` и `/med 22:22`. Проверь, что всё отвечает.

## Что обновлять при смене сайта
Картинки карты дня лежат на сайте в `/cards/`, списки цитат в `/day-quotes.json` и `/buddha.json`. Они публикуются вместе с сайтом.
Если меняешь цитаты: `node tools/make_cards.mjs` (нужен Chrome) → `node tools/build_app.mjs` → Push origin.

## Лимиты бесплатного тарифа (на дату написания)
- Worker: до 100 000 запросов в сутки; будильник раз в минуту это 1 440.
- D1: миллионы чтений в сутки, наши запросы очень лёгкие.
- За один запуск бот отправляет не больше 40 сообщений (лимит Cloudflare — 50 внешних запросов). Для личного проекта этого хватает.
Условия Cloudflare могут измениться: проверь страницу тарифов, если бот перестанет отвечать.

## Обновление уже работающего бота (новолуния)
1. D1 → `arcana-db` → Console → вставить текст из `bot/migrate-luna.sql` → Execute.
2. Worker `arcana-bot` → Edit code → заменить код на новый `bot/worker.mjs` → Deploy.
3. Открыть в браузере `/setup?key=…`, чтобы обновилось меню команд.
