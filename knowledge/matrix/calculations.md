# Расчёт

Обозначения (кириллические буквы схемы → ключи в коде): А, Б, В, Г, Д, Е, Ж, З, И → `A, B, V, G, D, E, Zh, Z, I`.

```
red(n): пока n > 22 — складываем цифры n (число ≤ 22 не меняется)
A  = red(день)               B = red(месяц)         V = red(сумма цифр года)
G  = red(A+B+V)              D = red(A+B+V+G)       — центр, зона комфорта
E  = A+B   Zh = B+V   Z = V+G   I = G+A            — родовые точки
```
Тройки вдоль линий (внутренняя = внешняя + центр, средняя = внешняя + внутренняя):
```
K = A+D   L = A+K     детско-родительская   (A, L, K)
M = B+D   N = B+M     духовно-творческая    (B, N, M)
O = V+D   P = V+O     материальная          (V, P, O)
R = G+D   S = G+R     кармический хвост     (G, S, R)
T = R+O   U = R+T     любовная              (R, U, T)
F = O+T               денежная              (O, F, T)
Kh = E+D  Ts = E+Kh   род отца, дух         (E, Ts, Kh)
Ch = Zh+D Sh = Zh+Ch  род матери, дух       (Zh, Sh, Ch)
Shch = Z+D  Y = Z+Shch  род отца, материя   (Z, Y, Shch)
Eh = I+D  Yu = I+Eh   род матери, материя   (I, Yu, Eh)
```
Предназначения: Небо = Б+Г; Земля = А+В; личное = Небо+Земля; мужское = Е+З; женское = Ж+И; социальное = мужское+женское; общее = личное+социальное; планетарное = социальное+общее. Сила рода = Е+Ж+З+И; код внутренней силы = сила рода + Д.
Проверка на опубликованных примерах: см. QA.
