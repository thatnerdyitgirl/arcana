# Спросить Матрицу

Не ИИ. Для темы выбираются позиции (роли), по каждой берётся энергия и поле текста; повторяющаяся энергия получает **другое** поле, тень показывается один раз; затем 1–3 строки о сочетании «стилей» энергий (act / feel / reflect / transform / integrate) и вопрос для проверки в жизни.
Темы: отношения (Р, У, Т), деньги (О, Ф, Т, В), самореализация (Небо, Земля, личное, социальное), я (А, Д, Б, Н), таланты (М, Х, Ч, Ф), текущий период (круг лет).
