# Возрастные периоды

Круг лет: А = 0, Е = 10, Б = 20, Ж = 30, В = 40, З = 50, Г = 60, И = 70. Каждый десятилетний отрезок делится серединами (сумма соседних): 5 лет → 2,5 и 7,5 → 1,25 / 3,75 / 6,25 / 8,75. Всего 64 точки с шагом 1,25 года.
Текущий период: точка, чей интервал содержит точный возраст. «Троичный код года»: текущая точка, точка напротив (+40 лет по кругу) и их сумма. Источник нумерации: опубликованный разбор (Прибылова), сверка по примеру 08.03.1960 (все значения совпали).
Округление подписей в источнике («1–2 года», «6–7 лет») приблизительно; Arcana использует точную сетку 1,25 года.
