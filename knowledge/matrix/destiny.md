# Предназначение

Три периода по методике: **личное** (Небо + Земля) — примерно до 40 лет, **социальное** (мужская + женская линии) — примерно 40–60, **общее** — энергия на всю жизнь, особенно после 60; **планетарное** = социальное + общее.
Язык Arcana: «в этой системе этап связывают с…», без оценки «выполнила / не выполнила» и без угроз.
