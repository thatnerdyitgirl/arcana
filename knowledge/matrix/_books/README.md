# Книги для сверки (приватно)

Сюда кладите файлы книг по Матрице судьбы (PDF, EPUB, DOCX, TXT), например:
- Альбина Матрикс — «Матрица судьбы от А до Я»
- Наталия Ладини — «Матрица судьбы. Первоисточник»

Содержимое этой папки **не попадает** ни в сайт, ни в GitHub (см. `.gitignore`). Из книг используются только формулы и факты для сверки; тексты Arcana остаются собственной редакцией, без копирования.
