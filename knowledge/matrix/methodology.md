# Методика Arcana: Матрица судьбы по системе Наталии Ладини

Arcana использует **одну** методику, не смешивая школы: классическую схему 22 энергий (диагональный и прямой квадраты) по линии Наталии Ладини.
Подробности, решения и расхождения школ: `docs/MATRIX-METHODOLOGY.md`. Проверка: `docs/MATRIX-QA.md`.

Главные решения:
- Числа больше 22 **складываются по цифрам** (23 → 5, 30 → 3). Альтернатива «вычитать 22» отмечена как другая школа и не используется.
- Энергии названы по Старшим арканам Таро в порядке 8 = Справедливость, 11 = Сила, 22 = Шут.
- Интерпретации — авторский синтез Arcana, в языке «в этой системе… может проявляться…».
- Матрица = постоянная карта; Таро = текущий вопрос; Луна = ритм дня; практики = действие. Эти системы не смешиваются математически.
