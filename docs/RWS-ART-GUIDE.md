# RWS-ART-GUIDE — лёгкие SVG-иллюстрации карт Райдера–Уэйта–Смит

Это **собственная** визуальная интерпретация ключевой сцены каждой карты, а не копия рисунков Памелы Колман Смит. Цель: пользователь глядит на плашку и узнаёт аркан по сюжету. Стиль Arcana: тонкая линейная графика, тушь (sumi-e), много воздуха, пара мягких пятен-вашей.

## Формат
- Файл: `knowledge/rws/art/RWS_MAJOR_19.svg`, `knowledge/rws/art/RWS_CUPS_06.svg` (id карты = имя файла).
- Корень строго: `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 120 200" role="img" aria-label="Солнце">`. Внутри `<title>` с русским названием. Рамку, фон и подпись рисует приложение, их не рисуй. Содержимое — внутри поля 10…110 по x и 12…188 по y.
- Весь линейный рисунок внутри `<g fill="none" stroke="currentColor" stroke-width="1.3" stroke-linecap="round" stroke-linejoin="round">`. Толщина линий 0.8–1.6 (акценты 2).
- Пятна цвета только готовыми классами (цвета берутся из темы приложения, светлая/тёмная тема подхватываются сами):
  - `wash` — лёгкая заливка тушью (`fill: currentColor; opacity .08`), для теней и масс;
  - `rose` — розовое пятно (акцент Arcana), `leaf` — зелёное, `sun` — тёплое солнечное, `mist` — туманный сине-серый.
  Использование: `<circle class="sun" cx="60" cy="50" r="22" stroke="none"/>`.
- **Запрещено:** `<style>`, `<filter>`, градиенты, `<image>`, `<text>`, `<script>`, внешние ссылки, `transform` длиннее одного `translate/rotate/scale`, цветовые коды (только классы и currentColor).
- **Лёгкость:** файл ≤ 3 КБ, не больше ~45 элементов, пути простые (без десятков точек). Рисунок должен читаться уже в 96 пикселей шириной.
- Использовать `rotate(180 60 100)` для перевёрнутых не нужно: приложение само поворачивает.

## Как рисовать
1. Выдели 3–5 «узнаваемых» элементов сюжета (они перечислены в задании у каждой карты) — только они обязательны, остальное упрощай.
2. Композиция вертикальная, фигуры упрощены до силуэтов-линий (кисть сумиэ: одна уверенная линия вместо детальной прорисовки). Лица без черт.
3. Одно акцентное пятно (`sun`, `rose`, `leaf` или `mist`) на один смысловой объект: солнце, цветок, кубок, плащ.
4. Хорошо оставлять фон пустым. Горизонт, холм, облако — одной линией.
5. Не копируй композицию оригинала по контурам: меняй ракурс, упрощай, но сохраняй сюжет.

## Проверка
`node tools/rws_art_gallery.mjs` собирает `build/rws-gallery.html` со всеми готовыми SVG на одной странице (светлая и тёмная тема) и сообщает размеры файлов и нарушения формата.
