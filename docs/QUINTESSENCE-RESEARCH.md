# QUINTESSENCE-RESEARCH — методы расчёта квинтэссенции

> 2 октября 2026 · исследование · **метод не выбран** — выбор за владельцем

## Главный вывод
Единственного правильного метода квинтэссенции нет. Разные школы считают по-разному в четырёх местах:
1. **как редуцировать** (сумма цифр или вычитание 22);
2. **чему равен Шут** (0 или 22);
3. **как считать придворные** (0, исключить, 11–14, 1–4…);
4. **какие карты включать** (все или только старшие).

Поэтому приложение должно всегда говорить «**по методу X** квинтэссенция = …».

## Методы

### М1. Немецкая традиция (Хайо Банцхаф)
| | |
|---|---|
| Источник | Немецкая Википедия «Tarot» (раздел «Quintessenz», ссылается на Х. Банцхафа); 100gadaniy.ru (приписывает метод Банцхафу) |
| Формула | сумма всех карт → сумма цифр, пока число > 22 |
| Старшие | по номеру |
| Шут | **22** («в квинтэссенции Шут = 22, а не 0») |
| Тузы | 1 |
| Числовые | по номиналу |
| Придворные | **0** |
| Уровни | вариант на 100gadaniy: числа 10–22 дают **две карты** (само число и сумма цифр); 19 → Солнце + Колесо + Маг; 22 → Шут + Император (2+2) |
| Перевёрнутые | вариант на 100gadaniy: значение со знаком минус (редкий вариант) |
| Трактовка | суть, ключ или совет всего расклада |
| Распространённость | основной метод в немецко- и русскоязычной практике |
| Противоречия | в немецких форумах встречаются альтернативные значения придворных (по поисковой сводке: Паж 10, Рыцарь 6, Королева 3, Король 2) — **первоисточник не найден, не использовать** |

### М2. Вычитание 22
| | |
|---|---|
| Источник | форум taro.lv (обсуждение практиков) |
| Формула | сумма; если > 22 — вычитать 22, пока не станет ≤ 22 |
| Шут | 0 или 22 — в обсуждении нет согласия |
| Придворные | часть участников: Паж 11, Рыцарь 12, Королева 13, Король 14; часть не учитывает |
| Уровни | не описаны |
| Трактовка | та же, что в М1 |
| Распространённость | заметное меньшинство в русскоязычной практике |
| Противоречия | на одних и тех же картах даёт другой результат, чем М1 (32 → 5 у М1, 32 → 10 у М2) |

### М3. Tirage en croix (Марсельская традиция)
| | |
|---|---|
| Источник | французская Википедия «Tirage en croix»; kartomanta.com; clesdutarot.com |
| Формула | 4 карты (только старшие арканы) → сумма; если > 22 — сумма цифр; результат — 5-я карта «синтеза» |
| Шут (Le Mat) | 22 (если сумма = 22, синтез = Le Mat) |
| Придворные | не участвуют (расклад только на старших) |
| Уровни | нет |
| Трактовка | синтез, итог, «ответ» креста |
| Распространённость | классика французской школы; по одному англоязычному автору, французские традиционалисты применяют расчёт **только** в этом раскладе |
| Важно для Манары | нумерация Манары совпадает с марсельской (8 = Справедливость), поэтому метод переносится без конфликта |

### М4. Англоязычная практика («Quint»)
| | |
|---|---|
| Источник | tarotbycher.blogspot.com; tarotforum.net; astrologyanswers.com; parsifalswheeldivination.org |
| Формула | сумма → сумма цифр до наибольшего числа ≤ 22 (48 → 12, **дальше 1+2 не складывают**); у некоторых до ≤ 21 |
| Шут | 0 или 22; parsifal настаивает на 0 |
| Придворные | 4 варианта: исключить; 0; Паж 11 … Король 14; Король 1 … Паж 4 |
| Альтернатива | parsifal: «отбрасывание девяток» (casting out nines) — может дать 0 и две карты-кандидата; сумма цифр, по его мнению, систематически не даёт 0 и крайних арканов |
| Трактовка | общая тема, урок; иногда долгосрочный итог |
| Распространённость | известна, но не основная техника |

### М5. Редукция до однозначного (нумерологический вариант)
| | |
|---|---|
| Источник | русскоязычные сайты (по поисковой сводке; конкретная страница не прочитана) — **низкая уверенность** |
| Формула | складывать цифры, пока не получится 1–9 |
| Трактовка | «глубинный» уровень; иногда используется как второй уровень после М1 |
| Комментарий | теряет старшие арканы 10–22; это скорее нумерология, чем таро |

## Пример на тестовых картах Манары

Карты: IX Отшельник, X Зеркало, Тройка Огня, Шестёрка Воздуха, Тройка Воды.
Сумма: 9 + 10 + 3 + 6 + 3 = **31**

| Метод | Расчёт | Результат (Манара) |
|---|---|---|
| М1 Банцхаф | 3 + 1 = **4** | IV Император |
| М1, уровни | 4 (однозначное) | IV Император |
| М2 −22 | 31 − 22 = **9** | IX Отшельник |
| М3 только старшие | 9 + 10 = **19** | XIX Солнце |
| М3 + уровни М1 | 19 → 10 → 1 | Солнце → **Зеркало** → Маг |
| М4 | 3 + 1 = **4** | IV Император |

Если добавить Королеву Воды: придворные 0 → сумма та же (31); Королева = 13 → 44 → **8 = VIII Справедливость в Манаре** (в RWS было бы 8 = Сила).

## Варианты для Arcana (ни один не объявлен правильным)

**Вариант A — «Основной метод + честная подпись».**
По умолчанию М1 (Банцхаф: придворные 0, Шут 22, сумма цифр до ≤ 22). Под результатом подпись: «По методу Банцхафа». Ссылка «другие методы» раскрывает М2 и М3.

**Вариант B — «Выбор школы в настройках».**
Пользователь один раз выбирает метод (М1 / М2 / М3) и параметры (придворные, Шут). Приложение всегда показывает расчёт целиком: `сумма → редукция → карта`.

**Вариант C — «Сравнение методов».**
Квинтэссенция показывается как небольшая таблица, как в примере выше: «по М1 — Император, по М2 — Отшельник, по старшим — Солнце». Совпадения подсвечиваются как более сильный сигнал. Это честнее всего, но перегружено для краткого ответа, поэтому подходит только для слоя «глубже».

Во всех вариантах:
- нумерация берётся **из колоды** (для Манары 8 = Справедливость);
- перевёрнутость на сумму не влияет, пока не выбран особый вариант;
- текст результата — «тема / ключ расклада», а не «ответ» или «итог».
