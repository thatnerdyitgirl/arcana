# MATRIX-METHODOLOGY — методика раздела «Матрица»

> 5 октября 2026. Порядок работы: исследование → методика → движок расчёта → база знаний → QA → интерфейс.

## 1. Выбранная методика

**Методика Arcana: Матрица судьбы по системе Наталии Ладини** — классическая схема 22 энергий: диагональный и прямой квадраты, девять основных точек (А–И), «тройки» вдоль линий, предназначения, круг лет.

## 2. Как велось исследование (и честные границы)

| Источник | Что удалось | Вывод |
|---|---|---|
| Н. Ладини, «Матрица судьбы. Первоисточник» (Эксмо, страница издателя) | Книга названа основной опорой в ТЗ, но **полный текст в среде разработки недоступен** | Прямой сверки с книгой нет. Требует вашей проверки |
| Официальный сайт matricaladini.ru, статьи «как рассчитать…» | Прочитаны 4 статьи | Тексты общие, противоречат друг другу (суммирование цифр даты как «число пути»), настоящих формул схемы в них нет. **Не использованы** |
| Е. Прибылова, «Матрица Судьбы. Карма и предназначение» (опубликованный фрагмент, глава «Расчёт») | Полные формулы точек и троек, предназначений, круга лет, числовой пример 08.03.1960 | Основной проверяемый источник формул |
| Практикум А. Дегтярёвой по методу Ладини (перепечатка, пример 26.08.1989) | Основная схема, предназначения, числовой пример | Независимое подтверждение схемы и сведения чисел |
| Другие книги из ТЗ (А. Матрикс, Е. Прибылова: полные версии) | Полные тексты недоступны | Не использованы; возможные альтернативные школы |

Две опубликованные схемы совпали между собой и со всеми проверенными числами (см. `docs/MATRIX-QA.md`).

## 3. Зафиксированные решения

1. **Сведение чисел.** Число ≤ 22 не меняется; число > 22 — сумма цифр, пока не станет ≤ 22 (23 → 5, 30 → 3, 87 → 15). Обе опубликованные схемы так делают.
   **Расхождение школ:** часть авторов вычитает 22 (25 → 3), что даёт другие значения. Это *альтернативная методика*, в Arcana она не реализована и не смешивается.
2. **Номера энергий:** 8 — Справедливость, 11 — Сила, 22 — Шут. Прибылова советует учитывать связь 8 и 11 (колоды меняют их местами); в базе есть пометка.
3. **Формулы** — см. `knowledge/matrix/calculations.md` (все основные и вспомогательные точки, предназначения).
4. **Круг лет** — 64 точки с шагом 1,25 года (подписи источника «1–2 года» округлены).
5. **Текущий период** — точка, содержащая точный возраст; «троичный код года» — текущая, противоположная (+40 лет), их сумма.
6. **Совместимость:** единой формулы в первоисточниках не найдено. Реализовано сложение одноимённых точек — **синтез Arcana**, помечен в интерфейсе и документации.
7. **Не реализовано сознательно:** «карта здоровья» (чакры, физика), генетические и судебные трактовки родовых линий, прогнозы с датами событий. Причины: медицинский характер, отсутствие подтверждённой методики, принципы Arcana (без диагнозов и предсказаний).

## 4. Язык интерпретаций

Только «в этой системе…», «может проявляться…», «в тени может указывать на…», «можно проверить, узнаёшь ли ты это». Запрещены (тест `tests/matrix.test.mjs`): «у тебя будет», «обречена», «токсичный», «манипулятор», «плохая энергия денег», проценты совместимости.

## 5. Архитектура

- `engine/matrix.mjs` — расчёт (чистые функции, без сети).
- `engine/matrix_text.mjs` — сборка текстов из базы знаний: зоны, «Спросить Матрицу», период, другой человек, пара, поиск.
- `knowledge/matrix/` — база: 22 энергии (`energies.json` + `energies/NN-*.md`), позиции, конфигурация тем, правила сочетаний.
- `tools/matrix_data/` — исходники базы и генератор (`python3 tools/matrix_data/build.py`), независимая сверка расчёта (`independent_check.py`).
- `app/matrix_ui.mjs` — интерфейс; дата рождения хранится в `localStorage` (`arcana-matrix-me`) и никуда не отправляется. Данные «другого человека» и пары не сохраняются.
- ИИ и API не нужны; позже ИИ можно добавить как отдельную опцию поверх `matrix_text.mjs`, ядро от него не зависит.
