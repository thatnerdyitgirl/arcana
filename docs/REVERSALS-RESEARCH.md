# REVERSALS-RESEARCH — перевёрнутые карты

> 2 октября 2026 · короткое исследование · **решение не зафиксировано**

| Школа | Перевёрнутые | Источник |
|---|---|---|
| Golden Dawn | **не используются**; смысл карты меняют соседи (элементальные достоинства: «хорошо / плохо достойна») | tarostarot.com, tarotsmith.com (вторичные) |
| Марсельская континентальная традиция | в основном **только прямые**; перевёрнутые значения появились в французском оккультном возрождении конца XVIII века | tarostarot.com (вторичный) |

## 2. Что говорят материалы Манары
- **Буклет Lo Scarabeo:** краткие прямые значения, перевёрнутых нет (Aeclectic).
- **Базовый русский текст:** только прямые. Негативные проявления даны через окружение («в неблагоприятном окружении — …»), то есть ближе к логике Golden Dawn, чем к переворотам.
- **Практики Манары:**
  - lunaro.ru, tarotman.ru, Зобова — перевёрнутых значений для Манары не дают;
  - Котлярова: Манара так подробно показывает нюансы отношений, что переворачивать её карты не нужно;
  - magicpeace.ru — даёт перевёрнутые значения без методологии и источников.

**Итог по Манаре:** основная линия — только прямые карты, а негативный аспект определяется соседними картами.

## 3. Плюсы и минусы трёх подходов

### 3.1 Только прямые
| Плюсы | Минусы |
|---|---|
| Соответствует буклету и основной практике Манары | Меньше «оттенков» в одной карте |
| Смысл определяется позицией, вопросом и соседями — совпадает с принципом Arcana `CARD × POSITION × QUESTION × CONTEXT × SURROUNDING` | Пользователи RWS могут ожидать переворотов |
| Меньше риска выдумать значения (для Манары источников нет) | |

### 3.2 Заблокированное / внутреннее проявление
| Плюсы | Минусы |
|---|---|
| Энергия карты не меняется на противоположную, меняется только способ проявления — мягко и психологично | Для Манары нет источников: это авторский синтез |
| Хорошо ложится на рефлексивный тон приложения | Риск размытых формулировок «что-то заблокировано» |
| Есть основание в литературе (Greer: blocked, internal) | Нужно писать отдельный слой для каждой карты |

### 3.3 Противоположное значение
| Плюсы | Минусы |
|---|---|
| Просто и понятно новичкам | Greer и Котлярова считают это упрощением: перевёрнутая карта не бывает полной противоположностью прямой |
| Есть у Уэйта (частично) | Для Манары ломает сюжет: противоположность «оборотня в изгнании» не определена |
| | Поощряет механическое чтение |

## 4. Предложение для Arcana (решение за тобой)
- **Манара:** по умолчанию **только прямые**. Негатив и оттенки — через позицию, вопрос и соседние карты.
- **RWS:** переключатель «учитывать перевёрнутые», режим **заблокированное / внутреннее** (основание — Greer). Справочно показывать перевёрнутое значение Уэйта.
- **Противоположное значение** не использовать как режим по умолчанию ни для одной колоды.
- Если пользователь всё же отметил карту Манары как перевёрнутую, приложение показывает: «В системе Манары перевёрнутых значений нет. Arcana читает эту карту через её теневую сторону (авторский синтез)».
