# Адаптер контекста — кто, с кем и что происходит

Итоговое чтение карты строится как **CARD × SUBJECT × RELATIONSHIP STATE × POSITION × QUESTION × CONTEXT**. Реализация: `engine/adapt.mjs`; интеграция в `engine/core.mjs` (reading), `engine/compose.mjs` (разбор карты), `engine/handoff.mjs`.

## Идея
У карты нет 78 × 12 текстов. Есть **контекстно независимое смысловое ядро** (грани), и **слой адаптации**, который по субъекту, состоянию связи и позиции выбирает грани и рамку.

### Грани карты (`cardFacets`)
| Грань | Источник (Манара) | Источник (RWS) |
|---|---|---|
| CORE | `ARCANA_SYNTHESIS.core_reading` | то же |
| STRENGTH / SHADOW | `IN_STRENGTH` / `IN_SHADOW` | `resource` / `shadow` |
| REL (RELATIONAL_DYNAMICS) | слой `relationships`, затем поле `relationships` | поле `relationships` |
| PSY (PSYCHOLOGICAL_DYNAMICS) | слой `psychology`, затем `psychology` | `psychology` |
| DESIRE / ATTRACTION | слой, у которого `focus` ∋ desire/attraction/passion/embodiment | контекстная линза с тегами desire/attraction |
| POWER / BOUNDARY | слой с `focus` ∋ power/control/boundaries/dependence | линза с тегами boundaries/conflict/coworker |
| CHANGE / POTENTIAL | `POSITIONAL_APPLICATION.tendency` (затем `advice`) | то же |
| WORK / SELF | слои `work` / `self_development` | `work_money` / `self_development` |
| VISUAL_FACT | `RECOGNITION.signature` | то же |

Грани берутся только из полей самой карты: Манара и RWS не смешиваются. DESIRE и POWER заполняются только там, где это релевантно (Манара: 62 и 76 из 78; RWS: 40 и 56 из 78).

### Субъект (`scanSubject`)
13 субъектов: я / внутренний процесс, новый человек, текущий партнёр, бывший, возможный будущий партнёр, человек, который притягивает, друг/подруга, коллега, деловой партнёр, начальник, команда, родственник, другой без уточнения. Берётся первый по тексту (рабочие роли приоритетнее); если в тексте никого нет — типичный для расклада (`SPREAD_SUBJECT`), иначе «другой человек» в «Отношениях» и «я» в остальных темах.

### Состояние связи
`new_relationship`, `existing_relationship`, `ex_relationship`, `no_contact`, `one_sided_interest`, `friendship`, `conflict`, `coworker`, `business_partnership`, `potential_future_relationship`, `family`, `sexual_attraction`, `inner_process`. Базовое состояние задаёт субъект, модификаторы (`no_contact`, `conflict`, `sexual_attraction`, `one_sided_interest`) — слова вопроса. Модификаторы сдвигают, какие грани читать первыми (конфликт → власть/границы, «нет контакта» → психология, и т. д.).

### Позиция (`positionIntent`)
Намерение определяется по названию позиции, затем по слоту `read`, затем по роли: shows, hidden, dynamic, meaning, remains, trend, gain, attraction, obstacle, want, action, self_side. Класс намерения (state / surface / depth / story / future / action) вместе с субъектом выбирает **рамку** (кто и что здесь читается) и **приоритет граней**. Одна карта в позициях «что он показывает», «что осталось после расставания», «куда движется связь» получает разные рамки и разные грани.

### Рамка и синтез
- Рамка карты: «В этой позиции карта может показывать …», «Если читать карту как состояние этой связи, она подсвечивает …», «Скорее всего, карта здесь обращает внимание на …» + объект, зависящий от субъекта и класса позиции (48 формулировок + уточнения для crush, будущего партнёра, начальника, команды, делового партнёра).
- Синтез (`situationFrame`): «Это расклад про {кто с кем}{, состояние}. Карты читают {линза вопроса}.» + оговорка «динамика и тенденция, а не точные мысли другого человека» (для бывшего без контакта — «связь читается в твоём восприятии…»). Линза вопроса: attracts / meaning / future / happening / shows / remains / act, для ключевых субъектов с отдельной формулировкой. Перспективная функция сохранена: «потенциал», «вероятная тенденция».
- Нероманические ситуации (дружба, работа, семья): романтические формулировки (страсть, влечение, партнёр, пара, близость…) отфильтровываются на уровне предложений; слой категории берётся рабочий или психологический, а не «Отношения».

## Что не менялось
UI, тексты карт и RWS. В шапке «Arcana слышит» добавляются метки субъекта и состояния (через уже существующий список контекста). Для «я / внутренний процесс» адаптер не вмешивается.

## Проверка
`tests/adapter.test.mjs`: распознавание (14 фраз), намерения позиций, грани у всех 156 карт, матрица 5 карт × 5 ролей и 78 карт × 5 ролей, позиция не теряется, нет романтики в дружбе/работе/семье, колоды не смешиваются, типы синтеза, нет повторов.
